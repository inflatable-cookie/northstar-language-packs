# Northstar Language Packs

Official optional language-quality packages for Northstar. Each package is an
independent release, acquisition, installation, and activation unit even when
several packages share this source repository.

## Start Here

- `docs/README.md`
- `AGENTS.md`

## Default Effigy Loop

```sh
effigy tasks
effigy doctor
effigy test --plan
effigy qa
```

## Current Focus

The first lane extracts `@northstar/typescript-quality` into
`packages/typescript`. See `docs/roadmaps/README.md`.
