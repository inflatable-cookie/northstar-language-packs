# Northstar Rust Audit

Thin explicit entrypoint for the canonical Rust audit route.

1. Load `references/modes/rust-quality-audit.md` from this package. It is
   the package's explicit audit authority.
2. Follow that mode's scope, finding-first record, repair-wave, preservation,
   and completion-evidence contract.
3. Treat text after `/northstar-rust-audit` as the target and requested
   worktree or repository scope.

Do not activate from ordinary Rust coding, broaden repair authority, or mutate
before the recorder contains the local finding and plan.
